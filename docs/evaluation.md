# Evaluation Plan

## Translation
Rate each example:
- 2 = correct/natural
- 1 = understandable but imperfect
- 0 = wrong/misleading

Track separately:
- meaning preservation
- Sheng slang interpretation
- code-switch handling
- naturalness
- unsafe/hallucinated additions

## Speech-to-text
Track word error rate where practical plus manual ratings for:
- Sheng terms
- Swahili words
- English insertions
- names
- noisy environments

## Human review
At least two fluent reviewers should adjudicate ambiguous slang before a record is marked `verified` for a production corpus.
